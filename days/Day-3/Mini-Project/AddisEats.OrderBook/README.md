# AddisEats.OrderBook

A C# console application for managing restaurant menu items,
customer orders, and sales reports.

## Features

- Menu item management
- Order creation
- Automatic order total calculation
- Filter orders by delivery area
- Calculate total ETB revenue
- Identify the busiest food category
- Paginate orders (5 per page)

## Technologies

- C#
- .NET
- LINQ
- Records and Classes
- Object-Oriented Programming

## Run the project

dotnet run
